# **App Name**: Localance

## Core Features:

- Quick Onboarding: Onboarding process with minimum required information for quick registration.
- Real-Time Task Notifications: Real-time task posting and notification system to alert nearby freelancers.
- Location-Based Search: Geolocation-based search to find freelancers and tasks within a specific radius.
- Freelancer Profiles: Profile section to highlight skills, past projects, and ratings.
- AI Skill Assessment: AI-generated skills assessment test to determine freelancer proficiency and placement in the 1% Club; the AI acts as a tool to evaluate applicants for 1% club.
- 1% Club Section: A members-only area for the most skilled freelancers on the platform
- Build Together Section: Collaboration Space for Freelancers

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) for trust and reliability.
- Background color: Light gray (#F0F2F5) to provide a clean and modern backdrop.
- Accent color: Yellow-orange (#FFA000) for calls to action and highlighting key elements.
- Headline font: 'Space Grotesk' sans-serif, for a modern and techy feel.
- Body font: 'Inter' sans-serif, for clean readability in longer texts.
- Use location-based icons for tasks, freelancer proximity, and category markers.
- Subtle, map-centric animations when viewing freelancer locations, along with notification animations when new tasks are posted nearby.
